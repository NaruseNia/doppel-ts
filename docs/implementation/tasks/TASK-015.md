### 実装概要

AST 解析 → 正規化 → Rust 類似度計算 → 出力の全パイプラインを統合し、フィクスチャープロジェクトによる E2E テストを整備する。

### 対象ファイル

- `packages/core/src/index.ts`（analyze 関数）
- `packages/cli/src/index.ts`（統合）
- `fixtures/small/**`
- `fixtures/medium/**`（生成スクリプト）

### 実装ステップ

1. core パッケージの `analyze()` エントリポイント関数を実装
2. CLI からの呼び出しフローを結合
3. フィクスチャープロジェクトの作成（明確な重複、微妙な類似、無関係）
4. 期待結果の文書化
5. スナップショットテスト（JSON 出力の一致確認）
6. ターミナル出力のスナップショットテスト
7. エッジケーステスト（空ディレクトリ、コンポーネントなしファイル等）
