# インフラ・配布・テスト 要件定義

## REQ-INFRA-001: pnpm monorepo 構成

| 項目       | 内容          |
| ---------- | ------------- |
| ID         | REQ-INFRA-001 |
| 優先度     | Must          |
| ステータス | Draft         |

### 説明

pnpm workspace による monorepo 構成を採用する。3パッケージ: `packages/core`（解析エンジン）、`packages/native`（Rust アドオン）、`packages/cli`（CLI）。

### 受入条件

- [ ] `pnpm-workspace.yaml` が構成されている
- [ ] `packages/core` が独立したパッケージとして動作する
- [ ] `packages/native` が独立したパッケージとしてビルド・公開できる
- [ ] `packages/cli` が `core` と `native` に依存する
- [ ] ルートから `pnpm build` で全パッケージをビルドできる

### 依存要件

- なし

| 優先度     | Must          |
| ステータス | Draft         |

### 受入条件

- [ ] `doppel-ts` パッケージ名で npm に公開できる
