# パフォーマンス 要件定義

## REQ-PERF-001: 小規模パフォーマンス目標

| 項目       | 内容         |
| ---------- | ------------ |
| ID         | REQ-PERF-001 |
| 優先度     | Should       |
| ステータス | Draft        |

### 説明

〜100 コンポーネント規模のプロジェクトに対する解析を数秒以内に完了する。具体的な目標値は実装時にベンチマークを通じて確定する。

### 受入条件

- [ ] 100 コンポーネントの解析が実用的な時間内に完了する
- [ ] ベンチマークテストで回帰が検知される

### 依存要件

- REQ-PERF-004（ベンチマーク回帰検知）

## REQ-PERF-004: ベンチマーク回帰検知

| 項目       | 内容         |
| ---------- | ------------ |
| ID         | REQ-PERF-004 |
| 優先度     | Must         |
| ステータス | Draft        |

### 説明

パフォーマンスの回帰を検知するベンチマークスイートを整備する。各規模のフィクスチャーに対する実行時間を計測し、閾値を超えた場合に警告する。

### 受入条件

- [ ] 小規模・中規模・大規模のベンチマークフィクスチャーが存在する
- [ ] ベンチマーク実行コマンドが用意されている
- [ ] 実行時間の基準値が設定されている
- [ ] 基準値からの乖離が一定割合を超えた場合にテスト失敗とする
- [ ] CI で定期的にベンチマークを実行する

### 依存要件

- REQ-INFRA-008（フィクスチャープロジェクト）
