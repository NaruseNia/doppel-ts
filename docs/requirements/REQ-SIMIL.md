# 類似度計算 要件定義

## REQ-SIMIL-001: 特徴ベクトル生成

| 項目 | 内容 |
|------|------|
| ID | REQ-SIMIL-001 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

各コンポーネントの正規化構造データから特徴ベクトルを生成する。Props 名・型情報、JSX タグ名・属性、構造パターンを数値化する。この処理は Rust ネイティブアドオンで実行される。

### 受入条件

- [ ] Props のプロパティ名・型をベクトル次元として反映できる
- [ ] JSX タグ名・属性名をベクトル次元として反映できる
- [ ] ツリーの深さ・分岐パターンをベクトルに反映できる
- [ ] 同一の入力に対して常に同一のベクトルを生成する（決定論的）

### 依存要件

- REQ-PARSE-002（Props 型抽出）
- REQ-PARSE-003（JSX ツリー抽出）
- REQ-NATIVE-002（特徴ベクトル生成 Rust 実装）

## REQ-SIMIL-002: コサイン類似度フィルタリング

| 項目 | 内容 |
|------|------|
| ID | REQ-SIMIL-002 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

全コンポーネントペア間のコサイン類似度を特徴ベクトルで計算し、閾値未満のペアを早期排除する。O(N²) のペア数を精密比較対象に絞り込むためのフィルタリングステップ。

### 受入条件

- [ ] コサイン類似度を正しく計算できる
- [ ] フィルタリング閾値を設定可能
- [ ] 閾値以上のペアのみを次の精密比較ステップに渡す
- [ ] 1000 コンポーネント規模で実用的な速度で動作する

### 依存要件

- REQ-SIMIL-001（特徴ベクトル生成）
- REQ-NATIVE-003（類似度計算 Rust 実装）

---

## REQ-SIMIL-003: Tree Edit Distance 精密比較

| 項目 | 内容 |
|------|------|
| ID | REQ-SIMIL-003 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

フィルタリングを通過したペアに対して、JSX ツリーの Tree Edit Distance を計算し、精密な類似度スコアを算出する。

### 受入条件

- [ ] 正規化された JSX ツリー間の編集距離を計算できる
- [ ] 編集距離を 0.0〜1.0 の類似度スコアに正規化できる
- [ ] 挿入・削除・置換の各操作を考慮する
- [ ] 属性の差異も距離に反映する

### 依存要件

- REQ-SIMIL-002（コサイン類似度フィルタリング）
- REQ-NATIVE-003（類似度計算 Rust 実装）

## REQ-SIMIL-004: Props 型類似度

| 項目 | 内容 |
|------|------|
| ID | REQ-SIMIL-004 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

2つのコンポーネントの Props 型を構造的に比較し、類似度スコアを算出する。プロパティの名前・型・オプショナル有無を考慮する。

### 受入条件

- [ ] 同名・同型のプロパティを一致として判定できる
- [ ] 名前が異なるが型が同一のプロパティを部分一致として扱える
- [ ] オプショナル有無の差異を類似度に反映できる
- [ ] `onClick: () => void` と `onSubmit: () => void` のような構造的類似を検出できる
- [ ] スコアを 0.0〜1.0 で出力する

### 依存要件

- REQ-PARSE-002（Props 型抽出）

---

## REQ-SIMIL-005: JSX ツリー類似度

| 項目 | 内容 |
|------|------|
| ID | REQ-SIMIL-005 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

2つのコンポーネントの JSX ツリーを構造的に比較し、類似度スコアを算出する。タグ名、ネスト構造、属性パターンを考慮する。

### 受入条件

- [ ] 同一のタグ構造を持つツリーを高類似と判定できる
- [ ] タグ名の差異を距離に反映できる（`<div>` vs `<span>` 等）
- [ ] ネストの深さやパターンの類似性を比較できる
- [ ] スコアを 0.0〜1.0 で出力する

### 依存要件

- REQ-PARSE-003（JSX ツリー抽出）
- REQ-SIMIL-003（Tree Edit Distance）

## REQ-SIMIL-008: 多段階閾値判定

| 項目 | 内容 |
|------|------|
| ID | REQ-SIMIL-008 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

類似度スコアを多段階で判定し、重要度レベルを付与する。デフォルトでは `high`（≥90%）と `medium`（≥70%）の2段階。

### 受入条件

- [ ] デフォルトで high（≥0.9）、medium（≥0.7）の2段階を提供
- [ ] `--threshold` フラグで閾値をカスタマイズできる
- [ ] `doppel.config.ts` で段階の追加・変更ができる
- [ ] 閾値未満のペアは出力から除外される

### 依存要件

- REQ-CONFIG-003（閾値設定）
- REQ-CLI-003（--threshold フラグ）
