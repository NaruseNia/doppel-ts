# CLI・出力 要件定義

## REQ-CLI-001: 位置引数によるスキャン対象指定

| 項目 | 内容 |
|------|------|
| ID | REQ-CLI-001 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

CLI の位置引数でスキャン対象のディレクトリや glob パターンを指定できる。引数なしの場合はカレントディレクトリ配下の全 TSX/JSX ファイルを対象とする。

### 受入条件

- [ ] `doppel src/components` でディレクトリ指定ができる
- [ ] `doppel src/components src/ui` で複数ディレクトリ指定ができる
- [ ] `doppel "src/**/*.tsx"` で glob パターン指定ができる
- [ ] 引数なしで cwd 配下の全 TSX/JSX を対象にする
- [ ] 存在しないパスを指定した場合にエラーメッセージを表示する

### 依存要件

- なし

## REQ-CLI-002: --exclude フラグ

| 項目 | 内容 |
|------|------|
| ID | REQ-CLI-002 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

スキャン対象からファイルやディレクトリを除外する。テストファイルや Storybook ファイルの除外を想定。

### 受入条件

- [ ] `--exclude "**/*.test.tsx"` でパターン除外ができる
- [ ] `--exclude "**/*.stories.tsx"` で Storybook ファイルを除外できる
- [ ] 複数の `--exclude` を指定できる
- [ ] `doppel.config.ts` の exclude と CLI フラグの exclude がマージされる

### 依存要件

- REQ-CONFIG-002（include/exclude 設定）

| 項目 | 内容 |
|------|------|
| ID | REQ-CLI-006 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

## REQ-CLI-009: リッチ JSON 出力（AI 消費向け）

| 項目 | 内容 |
|------|------|
| ID | REQ-CLI-009 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

JSON 出力のデフォルトはリッチモード。AI エージェントが消費することを想定し、各コンポーネントの Props 一覧、正規化 JSX ツリー、共通部分と差分部分の構造データを含む。

### 受入条件

- [ ] 各ペアに Props の完全な型情報を含む
- [ ] 正規化された JSX ツリー構造を含む
- [ ] 共通部分と差分部分を構造的に分離して表現する
- [ ] 各指標の内訳スコア（props、jsx、style、behavior）を含む
- [ ] メタデータ（スキャン日時、対象パス、設定値）を含む
- [ ] ソースコードのスニペットは含まない（ファイルパスと行番号で参照）

### 依存要件

- REQ-CLI-005（JSON 出力）
- REQ-PARSE-002（Props 型抽出）
- REQ-PARSE-003（JSX ツリー抽出）

---
