# Rust ネイティブアドオン 要件定義

## REQ-NATIVE-001: napi-rs Rust アドオン基盤

| 項目 | 内容 |
|------|------|
| ID | REQ-NATIVE-001 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

napi-rs を用いた Rust ネイティブアドオンの基盤を構築する。Node.js および Bun から呼び出し可能にする。

### 受入条件

- [ ] napi-rs によるネイティブアドオンがビルドできる
- [ ] Node.js (v20+) から正常に読み込み・実行できる
- [ ] Bun から正常に読み込み・実行できる
- [ ] プリビルドバイナリを提供する（linux-x64, darwin-x64, darwin-arm64, win32-x64）
- [ ] プリビルドが利用できない環境ではソースからビルドするフォールバック

### 依存要件

- REQ-INFRA-001（pnpm monorepo 構成）

## REQ-NATIVE-002: 特徴ベクトル生成（Rust）

| 項目 | 内容 |
|------|------|
| ID | REQ-NATIVE-002 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

TS 側で正規化された構造データを受け取り、Rust 側で特徴ベクトルを生成する。

### 受入条件

- [ ] 正規化構造データ（JSON シリアライズ可能）を入力として受け取れる
- [ ] 固定次元の特徴ベクトルを出力する
- [ ] バッチ入力（複数コンポーネント一括）に対応する
- [ ] 決定論的な出力を保証する

### 依存要件

- REQ-NATIVE-001（napi-rs 基盤）
- REQ-NATIVE-004（バッチ処理インターフェース）

---

## REQ-NATIVE-003: 類似度計算（Rust）

| 項目 | 内容 |
|------|------|
| ID | REQ-NATIVE-003 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

特徴ベクトル間のコサイン類似度、および正規化ツリー間の Tree Edit Distance を Rust で計算する。

### 受入条件

- [ ] コサイン類似度を計算できる
- [ ] Tree Edit Distance を計算できる
- [ ] 複数ペアの一括計算に対応する
- [ ] 計算結果をスコア + 内訳として返す

### 依存要件

- REQ-NATIVE-001（napi-rs 基盤）
- REQ-NATIVE-002（特徴ベクトル生成）

## REQ-NATIVE-004: バッチ処理インターフェース

| 項目 | 内容 |
|------|------|
| ID | REQ-NATIVE-004 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

TS → Rust 間の FFI オーバーヘッドを最小化するため、バッチ処理インターフェースを提供する。1回の呼び出しで複数コンポーネントの処理を完了する。

### 受入条件

- [ ] 全コンポーネントの正規化データを1回の FFI 呼び出しで渡せる
- [ ] ベクトル生成 → フィルタリング → 精密比較を Rust 側で一貫して実行できる
- [ ] 結果を一括で TS 側に返却できる
- [ ] FFI のシリアライズ/デシリアライズが処理時間の 10% を超えない

### 依存要件

- REQ-NATIVE-001（napi-rs 基盤）
